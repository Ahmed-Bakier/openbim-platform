# apps/web — Frontend

Next.js 16 (App Router) + React 19 + TypeScript (strict) + Tailwind CSS 4 + TanStack Query.
Will host the web UI and the IFC web viewer (viewer library chosen in Milestone 7, ADR required).

## Commands

Run from the repository root (`make web`, `make test-web`, ...) or here with pnpm:

| Command                             | What it does                                        |
| ----------------------------------- | --------------------------------------------------- |
| `pnpm dev`                          | Dev server with hot reload on http://localhost:3000 |
| `pnpm build` / `pnpm start`         | Production build / serve it                         |
| `pnpm lint`                         | ESLint (zero warnings allowed)                      |
| `pnpm typecheck`                    | Generate route types, then `tsc --noEmit`           |
| `pnpm test`                         | Vitest unit/component tests                         |
| `pnpm format` / `pnpm format:check` | Prettier                                            |

## Configuration

| Variable                   | Default                        | Notes                                             |
| -------------------------- | ------------------------------ | ------------------------------------------------- |
| `NEXT_PUBLIC_API_BASE_URL` | `http://localhost:8000/api/v1` | Inlined into the browser bundle **at build time** |

`make web` exports variables from the repo-root `.env`.

## Layout

```
src/
├── app/            # routes (App Router), root layout, client providers
├── components/     # UI components
└── lib/            # config and API client code (lib/api/*)
```

`AGENTS.md` is generated by Next.js and points AI coding tools to the version-matched docs in
`node_modules/next/dist/docs/`.
